# Hotfix 69 — Two-Player Chase and Touch Hold Fix

- Fixed the iPad/touch D-pad being destroyed on every server state refresh.
- D-pad controls now persist for the entire chase and support press-and-hold movement.
- Multi-touch direction combinations are supported for diagonal movement.
- Both the ball carrier and defender can move with keyboard or touch controls.
- Defender movement is faster than the ball carrier.
- Ball carrier remains confined to the left side of the pitch.
- Tackle radius starts small to prevent an immediate tackle on first input.
- A dramatic assisted lunge begins near the end of the chase.
- The tackle is guaranteed to trigger within five seconds.
- Bot defenders retain automatic chase behaviour.
