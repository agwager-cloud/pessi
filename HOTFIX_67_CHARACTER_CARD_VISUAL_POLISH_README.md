# Hotfix 67 — Character Card Visual Polish

This client-only visual update improves the CharacterSelectScene card layout.

## Changes

- Enlarged each footballer sprite.
- Brought the sprite, player name and country/jersey line closer together.
- Increased player-name and country text sizes.
- Retained responsive font sizing and two-line wrapping for long names.
- Kept dedicated non-overlapping name and country bands inside every card.
- No server protocol, room logic, tournament logic or selection behaviour changed.

## Deployment

- Upload the Hotfix 67 itch.io ZIP to update the live browser client.
- A Render server redeploy is not required for gameplay.
- Committing the source files to GitHub is optional but recommended to keep the repository current.
