# Hotfix 66 — Character Text Layout and Name Preview Audio

## Changes

- Reworked the character-card lower text area into two fixed, non-overlapping bands.
- Long names use smaller responsive type and may wrap to two lines without covering the country and jersey line.
- Moved and slightly reduced footballer sprites to preserve readable label space.
- Character-name commentary now plays immediately when a user taps a player card.
- Pressing **CONFIRM PLAYER** reserves the chosen player without replaying the name audio.
- Any remaining player-name preview is stopped when LobbyScene opens.
- Existing server-authoritative first-confirmed selection protection is unchanged.
